# 运行时契约（跨内核）

> **来源**：继承自云朵版 `Fairy-DSH-Exp/fairy-system/PONYTAIL-DESIGN.md` §「0.1.1 运行时契约（实测钉死，2026-09-13）」的 7 条。
> 2026-10-14 在本仓（dsh **0.2.0-rc.2**）逐条判定**适用性**，可机检的已转成单元测试
> （`fairy-system/test/compat-contracts.test.js`），违反即红。
>
> ⚠️ 7 条里有 4 条是为云朵版自己的插件（`fairy-modes` / `fairy-persona` / preset shim）而立的，
> 本仓没有这些包。**逐条照抄成测试是没有意义的**，所以下表明确标了「本仓适用性」。

## 契约表

| # | 原契约 | 本质 | 本仓适用性 | 落地方式 |
| --- | --- | --- | --- | --- |
| 1 | preset 行名必须是**字面字符串**，不接受 `!!js` 表达式名 | cordis discovery 把表达式名判为 "names no plugin" | ✅ **适用** | 机检：解析 `cordis.patch.yml`，断言 preset 行 `id`/`name` 无 `!!js`，且 `name` 是裸包名 |
| 2 | **组 id 必须 ≠ 子行 id** | 同名会让 loader 的 entry 自我为父，`_disabled()` 父链 while 循环**同步卡死**（CPU 100%、所有 API 挂起） | ✅ **适用** | 机检：遍历 patch 树，断言 `group: true` 的行 id 不出现在其子行里 |
| 3 | profile 行名必须是**裸包名**（不能是 `pkg/bridge` 这类子路径） | `clientModules` 按行名解析包的 `dsh.client`；子路径名会让客户端 bundle 进不了 boot 图（槽位 UI 不渲染**且无报错**） | ✅ **适用** | 机检：顶层 patch 行的 `name` 不含 `/`（`@scope/pkg` 例外） |
| 4 | 0.1.1 的 section 契约是**字面 order**；0.1.2+ 改 `getSectionOrder` | 写死数字会随代际漂 | ⚠️ **半适用**：本仓未自注册 systemPrompt 段落 | 只机检「代际探测存在」：`fairy-compat` 的 probe 必须用 `getSectionOrder` 判定代际，不许出现裸版本号比较 |
| 4b | 工具呈现取值随 cohort 改名（`code` → `ptc`） | 同上 | ⚠️ **半适用**：本仓未调 `presentAs` | 同上，归入代际探测 |
| 5 | 插件**不依赖 harness 子包**做独立安装 | 插件自有 `node_modules` 里出现 `@deepseek-ai/dsh-tools` 会解析出漂移的 peer 集合 → 加载即崩 | ✅ **适用** | 机检：扫 5 个插件包 `package.json` 的 dependencies，`@deepseek-ai/*` 只允许白名单（`dsh-settings`、`schemastery`） |
| 6 | preset 发现靠**复制**不靠链接；`readdir` 的 `Dirent.isDirectory()` 对链接/junction 返回假 | 链接形态会被静默跳过 | ✅ **适用** | 机检：断言仓内 `.agent-presets/fairy/` 全是**普通文件/目录**，无 symlink |
| 7 | 人格→语音绑定是**事件级联（异步）**：`select` 返回后同一秒内落盘 | 测试需容忍时序 | ❌ **不适用**：本仓无 `fairy-persona` 引擎（云朵版特性，属 P1/P2） | 不落地，记在此处备查 |

## 本仓额外固化的两条（来自 0.2.0-rc.2 实证）

| 契约 | 判别信号 | 落地 |
| --- | --- | --- |
| agent preset **不再扫描目录**，必须在 `profiles/<profile>/cordis.patch.yml` 注册成 `@deepseek-ai/dsh-agent-preset` 行 | 点新建会话零反应，客户端控制台 `agent-preset/not-found` | `tools/check-presets.mjs`（并断言 `selectedDefault` 指向一个**已注册**的 id） |
| 客户端 DOM 选择器跨代是**并集**（`[data-slot="conversation"], [data-slot="main.conversation"]`） | 诊断被误判成「应用未挂载」而整体跳过 | `fairy-visual/test/capability.test.js` 的假 DOM 夹具按逗号拆并集匹配 |
